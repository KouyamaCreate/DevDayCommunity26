# 変更記録

## 2026-10-18

### 変更

- 店舗・物件・経路に共通の根拠レコードと比較方針を追加。
- カフェ検索から周辺集計、参考候補の選択、既存地図カメラへの反映までをdiscoverで接続。
- HTTP・Web会話・MCPから利用可能にし、検証用サンプルによる自動テストと明示実行のライブ検証スクリプトを追加。
- README・プラグイン相談スキル・仕様を更新。

### 理由

地図情報と公開報告情報をエージェントが組み合わせて作業するため。渋谷とSFの位置精度・期間を混同せず、欠損や古い情報を安全扱いしない共通の仕組みにする。
