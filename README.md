# そこまで行って大丈夫？

全面地図と左下の相談窓で、自然言語から店・住所・物件候補・徒歩経路と公開報告情報を調べるローカルWebアプリです。地図を見るだけ、近くの店を探すだけでも使えます。

## 起動

Node.js 22以上で、リポジトリのルートから実行します。

```sh
npm ci --prefix plugins/sokomade
npm run build
npm start
```

[http://127.0.0.1:4184/](http://127.0.0.1:4184/)を開きます。Google Maps Platformのサーバー用・ブラウザ用キーは画面の設定から登録します。会話にはOpenAI APIキーが必要です。ルートの`.env.local`に`OPENAI_API_KEY`を設定するか、起動環境から渡してください。ファイルのキーを優先します。`.env.local`はGitから除外しています。モデルは`SOKOMADE_MODEL`で変更できます（既定`gpt-6.1-sol`）。

## 相談例

- 「SFを見せて」「この辺の公開報告を教えて」：出発地・行き先を決めずに利用。
- 「この辺でカフェを探して」：地図の注目地点や表示範囲から検索。出発地は不要。
- 「このホテルから、この店へ徒歩で往復したい」：実際の往路・復路と条件内の別経路を比較。
- 「物件AとBから職場までの徒歩を比較して」：住所・対応物件URLを追加し、物件→職場とその逆向きの経路を取得。
- 「遠回り5分まで、徒歩往復30分以内」：条件を相談中に保持。選択中の往復を秒で合計して判定。

地図のドラッグ・ズームは表示範囲、地図の空白部分のクリックは注目地点を更新します。徒歩の出発地とは別です。店やルートの選択は比較カードと地図で共有し、追加の店舗検索でも物件・選択済み地点・経路の比較対象を保持します。手動の地域切替も同じ相談を保ちます。

## 報告情報とデータ

- 地図・店舗・徒歩の検索はGoogleが対応する地域で利用可能。公開報告の接続先はSFと渋谷です。検索可能範囲と報告情報の対応範囲は別です。
- SFは匿名化された公開位置を平滑化した参考分布。地図を選ぶと、周囲250/500/1000mの公開報告の実件数を確認できます。表示の平滑化半径・色の濃さは実件数と独立しています。
- 渋谷は町丁目全体の認知件数を、CODH/e-Statの2020年国勢調査の参考境界で色分けします。現在の住所・警視庁集計区域との完全一致は未確認です。沿道件数・表示範囲内合計には変換せず、対応する報告がない地域は0件で埋めません。
- 未対応・取得不能・位置不明を0件や安全扱いにしません。地図全域の網羅性は未確認です。安全度スコア・安全保証・夜間リスク推定は行いません。
- 相談の地点・住所・URL・履歴・条件はサーバーのメモリのみ。無操作60分、破棄、サーバー終了で消えます。APIキー設定と地域全体の公開データだけをこのMacに保存します。
- 会話はOpenAIへ（`store:false`）、住所・店舗・経路はGoogleへ、物件URLはそのサイトへ送信します。各提供者側の保持は別です。サーバー用キーはブラウザに送りません。

127.0.0.1だけで待ち受けます。クラウド配備・公開サービス化は含みません。鉄道の時刻表・終電・配車は外部サービスへの案内です。空き物件を網羅検索する機能はありません。

既存のCloud環境の依存確認は`npm ci && npm run check:cloud`で実行できます。
