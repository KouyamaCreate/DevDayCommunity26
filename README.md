# そこまで行って大丈夫？

地図、公開された治安情報、建物の施設構成をつなぎ、行き先と経路を根拠付きで選べるプロジェクト。

[DevDay Community Hackathon: Tokyo](https://luma.com/OpenAIDevDay2026CommunityHackathonTokyo) の4つの審査基準に対する実装を示す。

## 新機能の活用

- **ChatGPT Sites**：渋谷の建物を探索する「CITY LIGHT」を公開。評価済みの建物データを含む静的版なので、閲覧者はAPIキーなしで2.5D地図、検索、絞り込み、評価の根拠を試せる（[実装仕様](apps/city-light/README.md)）。
- **Decisions API**：`gpt-6-luna` の `score` 質問で、施設がある3,297棟を建物ごとに評価。「人の目」40％、「支援施設」20％、「落ち着き」40％の3軸を合成し、モデル、評価日時、入力ハッシュ、APIリクエストIDを結果に保存する（[評価処理](apps/city-light/server/decisions.mjs)）。
- **GPT-6.1 Sol**：地図の表示範囲、選択地点、店舗、徒歩経路、公開報告を使う相談の既定モデルに採用。

## 使いやすさ

- 地図相談では全面地図と会話を同じ画面に置き、「この辺」を表示範囲、「ここ」を注目地点として扱う。出発地を指定せずにカフェを探せ、提案した候補を地図に反映する。
- CITY LIGHTでは建物、施設、住所を検索し、支援施設やスコアで絞り込める。真上と斜めの視点を切り替え、建物を選ぶと3軸の内訳、対応付け方法、出典、評価リクエストIDを確認できる。

## 有用性

- カフェ探し、徒歩の往復経路比較、指定した物件周辺の確認に、地図と公開報告を組み合わせる。サンフランシスコと渋谷で各3種類の相談を実際のGoogle、公開報告、OpenAIに接続して検証した（[回答と結果](docs/verification/pr4-live-consultations-2026-10-18.md)）。
- CITY LIGHTは渋谷駅から半径1kmの建物7,069件と施設19,687件を収録。施設のある3,297棟をDecisions APIで評価し、施設情報のない建物のうち3,770棟には町丁目全体の犯罪統計に基づく地域参考値を表示する。対応が曖昧な2棟は未評価として残す。

## 独創性

- 建物の明るさで施設構成に基づく環境参考スコアを表し、クリックすると数値と根拠に戻れる。明るさは実際の照明や昼夜、犯罪発生率を表さない。
- 建物ごとの施設評価と町丁目全体の地域参考値を画面上で区別する。欠測を0件や安全とみなさず、建物の評価と地域統計を同じ精度の値として扱わない。
- 地図相談でも出典、対象期間、集計範囲、位置精度、欠損状態を共通の根拠形式で示す。サンフランシスコでは同条件の公開報告を参考比較し、渋谷では町丁目件数から経路や店舗の安全順位を作らない。
