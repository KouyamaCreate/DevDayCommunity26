# そこまで行って大丈夫？

地図と治安に関する公開報告を使い、行き先と徒歩経路を根拠とともに検討できる地図相談アプリ。

[DevDay Community Hackathon: Tokyo](https://luma.com/OpenAIDevDay2026CommunityHackathonTokyo) の4つの審査基準に、次の実装で応える。

## 新機能の活用

DevDay 2026で発表された[GPT-6.1 Sol](https://openai.com/index/devday-2026-recap/)を会話の既定モデルに採用した。
地図上の場所と公開報告をエージェントが読み、カフェ候補の比較から根拠付き提案、地図上の選択までつなぐ。

## 使いやすさ

全面地図と相談窓を同じ画面に置く。
「この辺」は地図の表示範囲、「ここ」は注目地点として扱う。
カフェ探しに出発地の入力は不要で、提案した候補を地図に反映する。

## 有用性

カフェ探し、徒歩経路の比較、指定した物件周辺の確認に、地図と公開報告の両方を使う。
サンフランシスコと渋谷で、それぞれ3種類の相談を実際のGoogle、公開報告、OpenAIに接続して確認した。

## 独創性

場所と経路を、出典、期間、集計範囲、位置精度を示す共通の根拠形式で評価する。
サンフランシスコでは比較できる公開報告に限って候補を比べ、渋谷では町丁目全体の件数を示す。
渋谷の件数で候補に安全順位を付けず、公開報告が取得できない場所を0件と扱わない。
